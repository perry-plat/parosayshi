# Dia public brand archive

Collected on **2026-08-03** as a design-reference corpus, with the current Dia brand weighted more heavily than its historical states.

## Start here

- `docs/Dia_Current_Brand_System_and_Public_Asset_Atlas.docx` — the visual reference guide and design interpretation.
- `analysis/current-brand-brief.md` — a compact, searchable version of the current-state findings.
- `manifests/archive-summary.json` — corpus counts and collection scope.
- `manifests/images.csv`, `videos.csv`, `files.csv` — public asset manifests.
- `screenshots/` — rendered current and selected Wayback states.
- `previews/images/` — 563 content-linked image previews, transformed to a maximum width of 1200 px.
- `raw/sanity/` — the public Sanity content and asset records used for analysis.
- `raw/site/` — current public HTML and CSS snapshots.
- `raw/wayback/cdx-deduplicated.json` — 7,902 deduplicated public Wayback capture records from 2024–2026.
- `tools/collect-dia.mjs` — repeatable collector for refreshing the public corpus.

## Scope and limits

This is a public-web research archive, not an official Dia brand guide. It covers discoverable public pages, public Sanity records, current site code signals, public Mux references, and archived web captures available at collection time. It cannot include authenticated, privately held, unpublished, deleted, or robots-blocked material.

Commercial font endpoint URLs are catalogued for identification, but the font binaries are not redistributed. Original Sanity image URLs and Mux stream/poster URLs are catalogued; the archive keeps lighter preview copies rather than duplicating roughly 1.01 GiB of original imagery or more than two hours of video.

Use all third-party assets for reference unless you have confirmed permission for production use.
